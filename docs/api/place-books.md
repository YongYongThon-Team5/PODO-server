# 장소 관련 도서 API 연동 가이드

상태: 서버 구현 및 Swagger 계약 확인 완료. 프론트 코드는 포함하지 않는다.

## 조회

`GET /api/places/{placeId}/books` — 본문·쿼리 없이 호출한다. placeId는 공개 장소 목록/상세가 반환한 정식 UUID를 사용한다. 로그인 없이 사용 가능하며, 잘못된 Bearer를 보내면 기존 인증 필터가 401로 거절한다. 비공개/미존재 장소404, 잘못된 UUID·본문·쿼리400.

정상 응답은 `items`, `warnings`, `checkedAt`이다. `items`는 책별 title과 libraries(도서관 이름 문자열 목록)만 제공한다. 저자·출판사·연도는 잘못된 책을 연결하지 않기 위한 내부 비교에 사용하고 응답에서 제외한다. 자료실도 디자인에 없어 반환하지 않는다. 제공자 응답에서 확인된 제목과 도서관만 반환한다. checkedAt은 우리 서버 조회 시각이며 도서관 데이터의 갱신 시각이 아니다.

선정 목록 순서로 최대 3권을 제공한다. 같은 책의 도서관 이름 중복을 제거한다. Cache-Control은 no-store이며 X-Request-Id로 요청을 구분한다.

## 경고와 화면 처리

| 경고 | 의미 |
|---|---|
| NOT_CURATED | 해당 장소에 선정된 책이 없음. 목록은 빈 상태이며 외부 호출을 하지 않음 |
| PROVIDER_NOT_CONFIGURED | 키 또는 선정 설정이 준비되지 않음 |
| PROVIDER_UNAVAILABLE | 외부 통신·인증·제공자 응답 등에 문제가 있어 일부 또는 전체 조회 불가 |
| RESULTS_TRUNCATED | 해당 검색의 전체 결과가 100행보다 많음. 첫 100행에서 확인한 도서관만 포함 |
| CURATED_BOOK_NOT_FOUND | 처리한 조회 범위에서 선정한 서지와 일치하는 책을 찾지 못함 |

한 권 조회가 실패해도 다른 정상 도서는 표시할 수 있다. 경고는 위 순서이며 중복되지 않는다. 200 응답이어도 경고를 확인한다. 실패/미발견을 용인시 전체 미소장으로 안내하지 않는다. 이 API는 신간도서 조회 자료 범위만 확인한다.

‘현재 대출 가능’, 반납 예정일, 표지, ISBN은 응답하지 않는다. 도서관 이름을 받았다고 지금 대출 가능하다고 표현하지 않는다. 도서관 홈페이지에서 최신 이용 정보를 확인하도록 안내할 수 있지만 이 API가 개별 도서의 상세 URL을 제공하지는 않는다.

## 운영 선정 목록 설정

`YONGIN_LIBRARY_API_KEY`를 서버 환경변수로 전달한다. API 키 값은 프론트·문서·저장소에 넣지 않는다. 포털에서 복사한 raw/percent-encoded 키는 클라이언트 경계에서 한 번 정규화·인코딩한다. 키가 없는 상태에서도 기존 앱 기동은 유지된다.

`podo.books.recommendations`는 기본 빈 목록이다. 장소별 관련 책은 팀이 검수하여 설정한다. 아래는 구조 설명이며 모든 꺾쇠 값을 실제 데이터로 바꿔야 한다.

```yaml
podo:
  books:
    recommendations:
      - place-id: "<PUBLIC_PLACE_UUID>"
        books:
          - title: "<API bk_nm>"
            author: "<API aut_nm>"
            publisher: "<API pblshr>"
            publication-year: "<API pblcn_yr>"
```

선정값은 제공자에서 실제 조회한 서지 4개 값을 복사한다. ISBN이 없으므로 비슷한 제목이나 다른 저자·출판사·연도를 같은 판본이라고 추정하지 않는다. 앞뒤/연속 공백 외에는 정확하게 일치해야 한다. 장소별 최대 3권, 중복 UUID/서지·빈 필드·잘못된 연도는 유효한 선정 목록으로 사용하지 않는다. 임의의 Figma 예시나 테스트 fixture를 운영 목록으로 넣지 않는다.

초기 기본 설정만으로는 책이 표시되지 않는다. 실제 키와 검수된 장소별 서지 설정이 있어야 결과를 보여줄 수 있다. 키나 선정값이 없는 상태를 가짜 책으로 채우지 않는다.

## 외부 호출 범위와 검증 제한

[용인시 신간도서 API](https://www.data.go.kr/data/15097224/openapi.do)의 고정 HTTPS endpoint만 사용한다. 책당 pageNo=1·numOfRows=100, 요청당 최대 3회, 연결2초·응답5초, 자동 재시도 없음. 전체 소장 목록이나 실시간 재고를 보장하지 않는다. 별도 캐시·무제한 다음 페이지 검색·다른 공급자 fallback은 없다.

2026-11-12 수동 호출에서 전체 목록과 ‘애벌레’ 검색을 확인했고 Figma 예시 ‘배고픈 애벌레’는 첫 페이지에서 결과가 없었다. 응답에 오래된 반납 예정일이 있어 대출 의미·최신성을 확정하지 못했다. 신규 서버 구현은 합성 키·HTTP 스텁과 Testcontainers PostgreSQL로 검증했다. 최종 전체 테스트 395건과 관련 집중 테스트 24건이 통과했다. 실제 키를 이용한 신규 코드의 실시간 호출과 배포 환경 검증은 수행하지 않았다.

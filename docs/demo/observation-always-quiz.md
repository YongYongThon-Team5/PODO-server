# 사진 AI 퀴즈 긴급 안정화

AI 호출은 HTTP/1.1을 사용하고 요청 기본 대기시간은 180초(현재 검증 상한)다. Gemini 3.8 Flash에서 지원하는 thinking_level=low와 max_output_tokens=8192를 유지한다. minimal은 미지원이며 2048토큰으로 줄이지 않는다.

사진 단서가 부족하면 장소 자료 기반으로 3문항을 생성하도록 프롬프트를 수정한다. AI 통신 실패나 출력 검증 실패 시 서버가 저장된 장소 자료의 문구를 확인하는 기본 읽기 OX 3문항을 만든다. 기본 퀴즈임을 introduction과 photoEvidenceText에 명시하고 생성 메타데이터도 rule-based-source-reading/source-reading-v1로 기록한다. 사진을 분석한 사실로 꾸미거나 허위 출처를 생성하지 않는다.

정확히는 사진 업로드와 유효한 장소 자료가 확보된 작업에 대한 대체 생성이다. 사진 저장 실패, 장소 자료 없음, 방문 취소, 작업 중단, DB 장애까지 무조건 성공시키지는 않는다. 기존 source_id와 인용 일치 검증, 소유권과 방문 상태 검사, 작업 점유 검사는 유지한다.

자동 공개 기본값은 true로 변경했다. 서버 환경파일은 수정하지 않으며 기존 키를 사용한다. 서버가 환경변수 등으로 auto-publish=false 또는 다른 timeout을 명시한 경우 그 설정이 우선한다. AI enabled가 false거나 키가 비어 있는 상태를 우회하지 않는다.

프론트의 약 45초 지연 안내는 서버 작업을 중지하지 않는다. 오래 걸리면 상태 다시 확인을 사용한다. 과거 FAILED 작업은 코드 배포만으로 재실행되지 않는다. 재시도 버튼이 비활성화된 기존 방문은 미션의 방문 예정 취소 후 새 방문으로 테스트한다.

적용 스크립트는 인텔리제이에서 서버 프로젝트 루트 터미널을 열어 실행한다. 원본 파일을 백업하고 검토 원본과 다른 파일이 있으면 중단한다. 코드 적용과 로컬 검증만 수행하며 서버 환경파일 변경, 원격 서버 재시작, 커밋, 푸시, 배포는 하지 않는다. 실제 서버에는 수정된 JAR 재빌드/재배포가 필요하다.

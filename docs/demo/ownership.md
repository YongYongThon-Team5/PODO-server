## 도서 조사 증거와 제한

[용인시 신간도서 API](https://www.data.go.kr/data/15097224/openapi.do)는 도서명·저자·출판사, 도서관·자료실, 대출 여부·반납 예정일 등을 명세에 제공한다. 2026-11-12 실제 호출에서 전체 목록은 정상 응답했고 `애벌레` 검색은 총 59건, Figma 예시 `배고픈 애벌레` 검색은 첫 페이지에서 `NODATA_ERROR`였다. 이는 전체 미소장을 뜻하지 않는다. 응답에 2022년 반납 예정일이 포함되어 현재 대출 상태의 신뢰성 및 Y/N 의미를 추가 검증해야 한다. 인증키는 문서에 저장하지 않는다.

- 프론트에 임의로 계산한 레벨·칭호를 서버 신규 요구로 추가하는 작업
- 찜·후기·예약 등 Figma 근거가 확인되지 않은 기능

## 진행 순서

1. B·C가 본인 백엔드 항목을 기존 API 충족 / 수정 가능 / 결정 필요 / 불가로 분류한다.
2. 필수 변경과 기존 API 재사용 항목을 구분하고, 모호한 정책은 사용자 담당으로 남긴다.
3. B·C는 가능하고 명확한 서버 변경을 직접 수정·테스트하고 dev 대상 구현 PR을 올린다. 사용자 담당 작업은 별도로 진행한다.
4. 데모 장소를 정해 실제 콘텐츠·사진·계정으로 연결 확인한다. 스텁 테스트 통과를 실서비스 검증으로 대신하지 않는다.
